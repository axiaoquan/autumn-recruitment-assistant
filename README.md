# Autumn Recruitment Assistant · 秋招助手

一个完全离线、打开即用的校招投递与面试记录工具，支持 macOS 和 Windows。

不需要安装软件、不需要启动服务器，也不会访问招聘网站或把数据发送到网络。下载后只需打开 `index.html`。

## 功能

- 记录公司、岗位、城市、方向、招聘批次、投递日期和下一步行动；
- 按投递状态筛选，并在列表中快捷更新状态；
- 自动保留每次状态变化的历史；
- 记录面试轮次、时间、形式、问题、回答、追问、反馈和复盘；
- 展示投递公司数、岗位数、活跃流程、Offer 数及状态、方向、城市分布；
- 支持 JSON 完整备份与恢复，以及 CSV、Markdown 导入导出。

## 开始使用

### macOS

1. 点击 GitHub 页面右上角的 `Code` → `Download ZIP`；
2. 解压下载的文件；
3. 双击 `index.html`；
4. 如果系统询问打开方式，选择 Safari、Chrome、Edge 或 Firefox。

### Windows

1. 点击 GitHub 页面右上角的 `Code` → `Download ZIP`；
2. 解压下载的文件；
3. 双击 `index.html`；
4. 选择 Edge、Chrome 或 Firefox 打开。

建议以后固定使用同一个浏览器打开。不同浏览器的本地数据互不相通。

## 使用方法

### 记录投递

进入“投递”页面，点击“新增投递”，填写公司、岗位和当前状态。公司既可以从候选项中选择，也可以直接输入。

需要集中更新进度时，可以先按状态筛选，再在列表中逐条修改状态。

### 记录面试

进入“面试”页面，点击“记录面试”。面试可以关联已有投递，也可以作为独立面经保存。

面试记录按照面试时间倒序显示，越新的越靠上。

### 查看总览

“总览”页面会根据当前招聘批次展示投递数量、活跃流程、Offer 数、状态分布、方向分布、城市分布和近期事项。

## 数据保存与备份

填写的数据只保存在当前浏览器的本地存储中，不会写回 `index.html`，也不会自动上传到任何服务器。

以下操作前，请先进入“数据”页面导出“完整 JSON”：

- 清理浏览器缓存或网站数据；
- 更换浏览器；
- 移动或重装系统；
- 换电脑使用。

JSON 是完整备份格式，可以恢复公司、投递、状态历史和面试记录。导出的文件可能包含个人信息，请自行妥善保管。

## 导入与导出

- JSON：完整备份、合并和覆盖恢复；
- CSV：批量导入或导出投递记录；
- Markdown：导入公司与岗位信息，或导出便于阅读的记录。

需要迁移数据时，在旧设备导出完整 JSON，再在新设备的“数据”页面选择覆盖导入即可。

## 常见问题

### 关闭页面后数据还在吗？

正常情况下仍然保存在浏览器中。建议定期导出 JSON，避免浏览器数据被意外清理。

### 为什么换了浏览器后没有原来的记录？

不同浏览器使用独立的本地存储。请在原浏览器导出 JSON，再到新浏览器导入。

### 可以在手机上使用吗？

页面可以打开，但当前主要按照电脑浏览器设计，建议在 macOS 或 Windows 上使用。

### 会自动投递或访问招聘网站吗？

不会。它只是一个完全本地的记录工具，所有内容都由使用者手动维护。
